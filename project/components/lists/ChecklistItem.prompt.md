Vertical feature list used in the toolkit band — click-through rows where the active row drives the visual beside it.

```jsx
<ChecklistItem active icon={<i data-lucide="calendar-check" />} onClick={() => pick(0)}>
  Appointment reminders
</ChecklistItem>
```

- 20px weight 500 label, 24px icon tile, 8px gap, 16px vertical rhythm between rows.
- Active row: filled block at radius 16px — lavender on white, white on lavender.
